## Getting started 
- Essential Keyboard Shortcuts:
- Normal to Sketch: N
- Dimension: D
- Search/Shortcut Toolbar: S
- Isometric View: Shift + 7
- Hide/Show Sketches: Shift + H
- Hide/Show Planes: p
 ## Mouse NavigationRotate: Hold the Right Mouse Button (RMB) and drag
 - Pan: Hold the Middle Mouse Button (wheel) and drag, or hold Ctrl + RMB and drag
 - Zoom: Scroll the wheel up (in) or down (out)
 - Zoom to Fit: Double-click the Middle Mouse Button
